# Claude Mastery — Project Folder Guide

This project builds and tracks a world-class Claude enablement curriculum for BJ's.

## Folder structure

- **`CLAUDE.md`** / **`AGENTS.md`** — project context (auto-loaded). Keep at root.
- **`Claude_Mastery_Operating_System.md`** — the full curriculum, ecosystem map, and method. Keep at root (referenced by CLAUDE.md).
- **`01_Trackers/`**
  - `Claude_Mastery_Topic_Tracker.xlsx` — master tracker: 108 topics → 64 one-hour modules, Training Plan, rubric, sources, change log.
  - `Prompt_Pattern_Library.xlsx` — verified catalog of 75 prompting patterns (definition, when-to-use, BJ's example, provenance/source, value tier, module).
- **`02_Training_Decks/`** — one folder per module:
  - `M01_Core_Chat/`
  - `M02_Prompt_Engineering_I/` — Structure & Patterns
  - `M03_Prompt_Engineering_II/` — Reasoning & Self-Improvement
  - `M03b_Prompt_Engineering_III/` — Control, Reuse & Tools
- **`99_Archive/`** — superseded versions.
